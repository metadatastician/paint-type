== Current State (re-measured 2026-09-23)

The previous revision of this file (dated 2026-06-08) claimed the repository
was "fully licensed … with all SPDX identifiers aligned" and carried a
`Compliance` block of six ✅ marks. Measured against the tree, several of
those claims were false. They are replaced below with counted figures. The
counting command is reproduced at the end of this file so the numbers can be
re-derived rather than trusted.

* **SPDX Identifier:** `AGPL-3.0-or-later`

=== Open defects

These are known and unfixed. They are listed rather than papered over, and
each is tracked in the remediation plan.

. **144 first-party files carry no `SPDX-License-Identifier` header**
  (114 `.a2ml`, 24 `.adoc`, 6 `.sh`). A REUSE-conformant repository has one
  on every file.
. **34 `.adoc` files are tagged AGPL-3.0-or-later**, contradicting the
  stated policy that documentation is CC-BY-SA-4.0. Some of these may be
  deliberate (generated or machine-oriented documents); each needs a
  decision, not a blanket `sed`.
. **27 first-party files are tagged `PMPL-1.0-or-later`** — 14
  `.github/workflows/*.yml`, 7 `.machine_readable/…self-validating.ncl`,
  `.devcontainer/Containerfile`, `src/bridges/paint-type-layer.twasm`,
  `src/bridges/paint-type-tile.twasm`, `src/ui/app.js`, `src/ui/style.css`
  and `tools/abi-codegen/src/main.rs`. `PMPL` is not on the SPDX License
  List, so this tag does not resolve. The estate's own
  `.github/workflows/rhodibot.yml` rewrites `PMPL-1.0-or-later` to
  `AGPL-3.0-or-later` in dotfiles, which states the intended direction — but
  that workflow only touches dotfiles, so 27 files are outside its reach.
  (This file itself contains the string in the example command below; the
  counting recipe excludes it, which is why the figure is 27 and not 28.)
  Normalising them needs an owner ruling, because it is a licence change and
  not a typo fix.
. **`docs/licensing/PMPL-CAMPAIGN.adoc` does not exist.** The previous
  revision of this file linked to it, and the "PMPL Campaign Documentation"
  section below pointed at it as the record of the author's licensing
  philosophy. The link is dangling.

=== PMPL

The author advocates for the Palimpsest License as a licensing philosophy.
**PMPL is not the license of this repository.** AGPL-3.0-or-later is. The
28 `PMPL-1.0-or-later` tags listed above are therefore inconsistent with
this repository's own stated position, and are an open defect rather than a
deliberate choice.

Note that this section previously pointed at
`docs/licensing/PMPL-CAMPAIGN.adoc` for the campaign documentation. That
file is absent.

=== Verification

To re-derive the counts in the table above, excluding `third_party/`:

[source,bash]
----
python3 - <<'PY'
import re, os, collections
c = collections.Counter()
for root, dirs, files in os.walk('.'):
    parts = root.split(os.sep)
    if '.git' in parts or 'third_party' in parts:
        continue
    for f in files:
        ext = os.path.splitext(f)[1].lower()
        if ext not in ('.rs', '.zig', '.idr', '.sh', '.adoc', '.a2ml'):
            continue
        try:
            text = open(os.path.join(root, f), encoding='utf-8',
                        errors='ignore').read(2000)
        except Exception:
            continue
        m = re.search(r'SPDX-License-Identifier:\s*([A-Za-z0-9.+\-]+)', text)
        c[(ext, m.group(1) if m else 'NONE')] += 1
for (ext, lic), n in sorted(c.items()):
    print(f'{n:5}  {ext:8} {lic}')
PY
----

A simpler spot-check — note that `grep "SPDX-License-Identifier: PMPL"` also
matches `PMPL-1.0-or-later`, so anchor it:

[source,bash]
----
# Files tagged with a PMPL variant (should be 27). This file is excluded:
# it contains the pattern in the example itself and would self-match.
grep -rl "SPDX-License-Identifier:[[:space:]]*PMPL" . \
  | grep -v third_party | grep -v LICENSE-STATUS | wc -l

# Files whose LICENSE tag is exactly the bare string "PMPL" (should be 0)
grep -rn "SPDX-License-Identifier:[[:space:]]*PMPL\([^A-Za-z0-9._+-]\|$\)" . | grep -v LICENSE-STATUS
----

The root `LICENSE` should be byte-identical to the SPDX reference text:

[source,bash]
----
cmp LICENSE LICENSES/AGPL-3.0-or-later.txt && echo IDENTICAL
----
