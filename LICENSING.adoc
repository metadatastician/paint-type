= Licensing
:description: How paint.type is licensed, and why LICENSE holds only the AGPL text

[NOTE]
====
This content was previously the *entire* root `LICENSE` file. That is why
GitHub reported this repository's licence as `NOASSERTION`: GitHub detects a
project licence by matching the root `LICENSE` against reference licence
texts, and a 1,376-byte prose notice about dual licensing matches none of
them.

As of 2026-09-23 the root `LICENSE` holds the verbatim AGPL-3.0 text
(byte-identical to `LICENSES/AGPL-3.0-or-later.txt`), so detection resolves
to `AGPL-3.0-or-later`. Everything below — the scope split, the copyright
lines and the third-party component notice — is unchanged, just relocated
here where prose belongs.
