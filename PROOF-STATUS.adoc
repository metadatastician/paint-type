**Agda strict profile (PROOF-POLICY §2.1).** `Compositing.agda` and `TileCRDT.agda` now
carry `{-# OPTIONS --safe --without-K --cubical-compatible #-}`, and CI and
`just proof-check-agda` pass the same flags. With `--safe` the checker itself rejects
any `postulate` or `TERMINATING` pragma, so "no postulates" no longer rests on a comment.
Checked locally on 2026-11-17 with Agda 2.8.0.2: both modules exit 0.
`TileCRDT.agda` reports three `UnsupportedIndexedMatch` warnings (`≤-trans`,
`≤-antisym`, `<-irrefl`): those clauses would not compute on transports under full
Cubical Agda. They do not weaken the `--without-K` proof, and no warning is suppressed.
The earlier `--no-libraries`-only CI runs are historical evidence, not receipts for the
§2.1 profile (§2.1); the first strict CI receipt is the run on the PR that introduced
it. CI installs Agda from apt, so its version is not pinned (an open §2.1 item).

`verification/proofs/agda/Properties.agda` is an unwired template, not an obligation.
It imports agda-stdlib and does not check with `--no-libraries`. It is not counted.

## Verification Commands

```bash
# Check Idris2 proofs (ABI bridge in src/interface, verified modules in verification/)
# idris2 --check takes one file per invocation.
(cd src/interface && for f in Abi/Types.idr Abi/Layout.idr Abi/Foreign.idr; do idris2 --check "$f"; done)
(cd verification/proofs/idris2 && for f in ABI/Platform.idr ABI/Compliance.idr Pixel.idr TilePool.idr; do idris2 --check "$f"; done)

# Check Lean4 proofs (TP-2 public API type safety, INV-2 undo monotonicity) — pure core Lean4
lean verification/proofs/lean4/ApiTypes.lean
lean verification/proofs/lean4/UndoGraph.lean

# Check Agda proofs (INV-3, CONC-1, CONC-2) under the PROOF-POLICY §2.1 profile.
# --no-libraries avoids the broken global ~/.agda/libraries path; the files have
# zero library dependencies. Or: STRICT=1 just proof-check-agda
(cd verification/proofs/agda && for f in Compositing.agda TileCRDT.agda; do
  agda --no-libraries --safe --without-K --cubical-compatible "$f"; done)

# Run Zig FFI tests
cd src/interface/ffi && zig build test

# Run Rust Ephapax tests
cd src/paint_core && cargo test

# Run aspect tests (SPDX, dangerous-pattern, ABI/FFI contract, RGBA16F constants, …)
bash tests/aspect_tests.sh

# Scan for dangerous patterns
panic-attack assail --proofs-only

# Run all proof checks (when infrastructure is wired)
just proof-check-all
```
