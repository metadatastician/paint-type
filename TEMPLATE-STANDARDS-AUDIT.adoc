== Maintenance Model Note

* Protocols central: maintained in `standards/session-management-standards/`.
* Policy local: maintained in this repo (`session/*.k9`, hooks, coordination bindings).
* State per-repo: generated during execution (`.session/*`) in the active working repository.
* Machine-readable: `STATE.a2ml`, `ECOSYSTEM.a2ml`, `META.a2ml` generated from live tree. This audit document: regenerated from live tree via `just standards-audit` — CANNOT silently go stale (was v1.1/2026-06-01, now v1.2/2026-07-26).
* Contractile trident: local copies in `.machine_readable/contractiles/` based on canonical templates from `hyperpolymath/standards/.machine_readable/contractiles/`.
* CI/CD reusables: pinned to `hyperpolymath/standards` HEAD (2b6d30bb).
