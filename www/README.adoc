= www
:description: Static site for paint.type project

This directory contains the static site for the paint.type project, generated
using link:https://github.com/hyperpolymath/ddraig-ssg[ddraig-ssg] — a dependently-typed
static-site generator written in pure Idris 2.

== Purpose

The `www/` directory hosts the official paint.type static website, including:

- Project documentation
- Getting started guides
- Architecture overviews
- API references
- Demo showcases with representative images

== Tooling and Security

This static site is generated using *ddraig-ssg* (Welsh for _dragon_ — "types that breathe fire").

=== Dependency Pinning

* *Tool*: `ddraig-ssg`
* *Language*: Idris 2 (0.8.0+)
* *Source*: https://github.com/hyperpolymath/ddraig-ssg
* *Build*: `idris2 Ddraig.idr -o ddraig`
* *Verification*: `idris2 --check Html.idr` (type-checked HTML core)

=== Proof-Carrying Accessibility

Ddraig-ssg provides WCAG 2.2 AAA-capable accessible output with proof-carrying
guarantees:

* Every page carries an echo witness that its output is the render of an accessible source
* Machine-decidable WCAG criteria are theorems, not conventions
* The build fails if any page is un-attestable
* Accessibility attestation emitted at `/.well-known/accessibility-attestation.json`

=== Escaping Contract

The ddraig-ssg templating engine provides the following escaping guarantees:

* Front-matter fields (`title`, `description`, `date`, etc.) are automatically HTML-escaped
* Markdown content is parsed into typed HTML nodes and emitted by a total `render` function
* Image nodes cannot be constructed without non-empty alt text (WCAG 1.1.1 by construction)
* Raw HTML passthrough is supported but the template trust model assumes markdown content
  is generated from trusted repository files

=== Security Headers

The site enforces strict security headers (embedded via `<meta>` tags and served as
HTTP response headers):

* **Content-Security-Policy (CSP)**: `default-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; form-action 'self'; upgrade-insecure-requests`
* **X-Content-Type-Options**: `nosniff` — prevents MIME-sniffing attacks
* **X-Frame-Options**: `DENY` — prevents clickjacking
* **X-XSS-Protection**: `1; mode=block` — enables browser XSS filter
* **Referrer-Policy**: `no-referrer` — limits referrer information

== Source Layout

A ddraig-ssg site directory may contain:

----
src/
  index.md              # pages (front-matter + Markdown)
  getting-started.md    # getting started guide
  architecture.md       # architecture overview
  templates/
    default.html        # layout (overrides the built-in)
    partials/header.html
  assets/style.css      # copied as-is
  assets/images/       # project images and screenshots
  public/               # copied to the OUTPUT ROOT
    CNAME
    .well-known/security.txt
----

== Building the Site

To build the static site:

. Ensure ddraig-ssg is installed:
   - Clone: `git clone https://github.com/hyperpolymath/ddraig-ssg`
   - Build: `cd ddraig-ssg && idris2 Ddraig.idr -o ddraig`
   - Verify: `./build/exec/ddraig --version`
   - Verify proofs: `idris2 --check Html.idr`

. Run the site generator:
   - `ddraig build src _site https://paint.type`

. The generated files will be placed in `_site/`

. Clean with: `ddraig clean _site`
