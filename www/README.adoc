=== Escaping Contract

The casket-ssg templating engine provides the following escaping guarantees:

* `{{title}}` & `{{description}}`: Automatically HTML-escaped by `casket-ssg` at template compilation time to prevent XSS (Cross-Site Scripting) attacks.
* `{{content}}`: Raw HTML block generated from Markdown. *SECURITY NOTE*: The template trust model assumes markdown content is generated from trusted repository files and contains no unescaped user-controlled input. Do NOT use `{{content}}` with untrusted user input.

=== Security Headers

The site enforces strict security headers:

* **Content-Security-Policy (CSP)**: `default-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; form-action 'self'; upgrade-insecure-requests`
* **X-Content-Type-Options**: `nosniff` — prevents MIME-sniffing attacks
* **X-Frame-Options**: `DENY` — prevents clickjacking
* **X-XSS-Protection**: `1; mode=block` — enables browser XSS filter
* **Referrer-Policy**: `no-referrer` — limits referrer information

These headers are embedded in templates via `<meta>` tags and can also be served
as HTTP response headers from the host.

=== Building the Site

To build the static site:

. Ensure casket-ssg is installed at the pinned version:
   - Clone: `git clone https://github.com/hyperpolymath/casket-ssg`
   - Checkout: `git checkout 8c3b772b144e59df29c66cb1a8c3d9a4b276ff11`
   - Verify: `casket-ssg --version`

. Run the site generator (consult casket-ssg documentation for exact commands)

. The generated files will be placed in the output directory
